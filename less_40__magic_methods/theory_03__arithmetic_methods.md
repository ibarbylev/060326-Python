## Арифметические dunder методы

Это специальные методы, которые позволяют объектам участвовать в арифметических операциях.  

Они определяют, что будет происходить при использовании операторов `+`, `-`, `*`, `/`, `//`, `%`, `**` и др.



### ➕ Сложение

| Оператор | Метод                   | Описание                                     |
| -------- | ----------------------- | -------------------------------------------- |
| `a + b`  | `__add__(self, other)`  | Прямое сложение                              |
| `b + a`  | `__radd__(self, other)` | Обратное сложение (если у `b` нет `__add__`) |
| `a += b` | `__iadd__(self, other)` | Увеличение на месте                          |

---

### ➖ Вычитание

| Оператор | Метод      |
| -------- | ---------- |
| `a - b`  | `__sub__`  |
| `b - a`  | `__rsub__` |
| `a -= b` | `__isub__` |

---

### ✖️ Умножение

| Оператор | Метод      |
| -------- | ---------- |
| `a * b`  | `__mul__`  |
| `b * a`  | `__rmul__` |
| `a *= b` | `__imul__` |

---

### ➗ Деление

| Оператор | Метод          |
| -------- | -------------- |
| `a / b`  | `__truediv__`  |
| `b / a`  | `__rtruediv__` |
| `a /= b` | `__itruediv__` |

---

### // Целочисленное деление

| Оператор  | Метод           |
| --------- | --------------- |
| `a // b`  | `__floordiv__`  |
| `b // a`  | `__rfloordiv__` |
| `a //= b` | `__ifloordiv__` |

---

### % Остаток

| Оператор | Метод      |
| -------- | ---------- |
| `a % b`  | `__mod__`  |
| `b % a`  | `__rmod__` |
| `a %= b` | `__imod__` |

---

### ** Возведение в степень

| Оператор  | Метод      |
| --------- | ---------- |
| `a ** b`  | `__pow__`  |
| `b ** a`  | `__rpow__` |
| `a **= b` | `__ipow__` |

---

### Унарные операции

| Оператор | Метод              | Пример              |
| -------- | ------------------ | ------------------- |
| `+a`     | `__pos__(self)`    | Унарный плюс        |
| `-a`     | `__neg__(self)`    | Унарный минус       |
| `abs(a)` | `__abs__(self)`    | Абсолютное значение |


---

### Пример использования

Вот минимальный пример класса, который поддерживает арифметику:

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)
    
    def __sub__(self, other):
        return Vector(self.x - other.x, self.y - other.y)
    
    def __mul__(self, k):
        return Vector(self.x * k, self.y * k)
    
    def __repr__(self):
        return f"Vector({self.x}, {self.y})"


v1 = Vector(1, 2)
v2 = Vector(3, 4)

print(v1 + v2)   # Vector(4, 6)
print(v1 * 3)    # Vector(3, 6)
print(v2 - v1)   # Vector(2, 2)
```

### In-place арифметические dunder-методы

| Оператор  | Метод                        | Пример                                |
| --------- | ---------------------------- | ------------------------------------- |
| `x += y`  | `__iadd__(self, other)`      | сложение с присваиванием              |
| `x -= y`  | `__isub__(self, other)`      | вычитание с присваиванием             |
| `x *= y`  | `__imul__(self, other)`      | умножение с присваиванием             |
| `x /= y`  | `__itruediv__(self, other)`  | деление с присваиванием               |
| `x //= y` | `__ifloordiv__(self, other)` | целочисленное деление с присваиванием |
| `x %= y`  | `__imod__(self, other)`      | остаток с присваиванием               |
| `x **= y` | `__ipow__(self, other)`      | возведение в степень с присваиванием  |

⚠️ **Важно**:  
* если `__iadd__` (или аналог) не определён, то 
  * Python автоматически вызывает обычный метод (`__add__`, `__sub__` и т.д.) 
  * и присваивает результат обратно переменной.

---

### Пример с `Vector`

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    def __repr__(self):
        return f"Vector({self.x}, {self.y})"
    
    # In-place сложение
    def __iadd__(self, other):
        self.x += other.x
        self.y += other.y
        return self
    
    # In-place вычитание
    def __isub__(self, other):
        self.x -= other.x
        self.y -= other.y
        return self

v1 = Vector(1, 2)
v2 = Vector(3, 4)

v1 += v2
print(v1)  # Vector(4, 6)

v1 -= Vector(1, 1)
print(v1)  # Vector(3, 5)
```

⚠️ **Важно**: 

Обратите внимание, что именно возвращают методы `__add__` и `__iadd__`:

* метод `__add__` возвращает новый объект
* а метода `__iadd__` возвращает изменённый "старый"

Благодаря этому для `mutabel` объекта 
* операция `+` — это всегда возвращение объекта с новым `id()`
* а операция `+=` — изменяет объект по тому же адресу.
