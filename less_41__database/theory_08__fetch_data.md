## Извлечение данных из курсора MySQL

Перед тем как разбирать методы `fetch*`, важно понять, 
**в каком виде курсор возвращает данные**.

---

### 1. Формат данных курсора

#### 1.1. Обычный курсор (по умолчанию)

```python
cursor = connection.cursor()
```

Результат:

```
[
    (2974, 'Paris', 'FRA', 'Île-de-France', 2125246),
    (3068, 'Berlin', 'DEU', 'Berliini', 3386667),
    ...
]
```

* Возвращается `tuple`
* Доступ к данным — **по индексам**
* Зависимость от порядка колонок

---

#### 1.2. Курсор со словарями

```python
cursor = connection.cursor(dictionary=True)
```

Результат:

```
[
    {'CountryCode': 'FRA',
      'District': 'Île-de-France',
      'ID': 2974,
      'Name': 'Paris',
      'Population': 2125246},
     {'CountryCode': 'DEU',
      'District': 'Berliini',
      'ID': 3068,
      'Name': 'Berlin',
      'Population': 3386667},
      ...
]
```

* Возвращается `dict`
* Доступ по именам колонок
* Код становится устойчивым к изменению порядка полей

---

### 2. Способы извлечь данные из курсора

Есть несколько методов (и способов) извлечь данные из курсора

#### 2.1. `cursor.fetchone()`

```python
cursor.execute("SELECT * FROM city WHERE ID = %s", (1,))
row = cursor.fetchone()
```

* Возвращает **одну строку** (которая либо `tuple`, либо `dict`)
* Возвращает `None`, если данных нет
* Используется, когда ожидается ровно одна запись

```python
if row:
    print(row['Name'])
```

---

#### 2.2. `cursor.fetchall()`

```python
cursor.execute("SELECT * FROM city LIMIT 3")
rows = cursor.fetchall()
```

* Возвращает **список строк** (точнее, либо `list[tuple]`, либо `list[dict]`)
* Может быть пустым списком
* Подходит для небольших выборок

```python
for row in rows:
    print(row['Name'])
```

---

#### 2.3. `cursor.fetchmany(n)`

```python
cursor.execute("SELECT * FROM city")
rows = cursor.fetchmany(5)
```

* Возвращает список из `n` строк (`list[tuple]` или `list[dict]`)
* Удобно для постраничной обработки
* Меньше потребление памяти

---

#### 2.4. Итерация по объекту `cursor`

По сути, курсор — это итератор.  
Поэтому, он легко "разбирается"
* и циклом `for`
    ```python
    for row in cursor:
        print(row['Name'])
    ```

* и с помощью `unpacking`.
    ```python
    print(*cursor, sep="\n")
    ```

⚠️ Важно помнить, что итератор не содержит в себе данных.  
Поэтому для больших и объёмных таблиц, он является самым лучшим выбором.

    ⚠️ Не менее важное уточнение:
    По умолчанию курсор в mysql.connector буферизованный — он загружает весь результат в память.
    Чтобы действительно экономить память на больших выборках, нужно создавать курсор с buffered=False.
    Так что итерация по курсору действительно хороша, но только при правильной настройке!
---

### 3. Когда и что лучше использовать?

```md
| Метод        | Когда использовать                    |
|--------------|--------------------------------------|
| fetchone()   | Ожидается одна строка                |
| fetchall()   | Маленькая выборка                    |
| fetchmany()  | Пакетная обработка                   |
| Итерация     | Большие объёмы данных                |
```
